製作流程: 首先開啟一個 3D 專案，並在網路上找並導入需要的素材(寶可夢、
訓練家、球、粒子效果、音效、環境素材)，然後用 Terrain 拉山地的地形、種
樹，然後去小畫家畫地形的貼圖並導入，然後再用 Terrain 畫上去，接下來擺
好物件之後建立球的腳本，讓他可以以拋物線接觸到寶可夢並以鼠標瞄準左鍵
丟球，最後再搭載上音效及粒子效果即完成。
